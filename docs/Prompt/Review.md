# Review.md — 每日复盘 AI Prompt

> 集中维护「每日复盘」相关的 AI 能力。当前对应本地规则 `AI.selfAnalysis` 的部分思路。

## 作用

引导用户完成高质量每日复盘，并把复盘沉淀为可执行的明日行动。

## 适用场景

- 今日页 / 复盘入口的「今日复盘」引导与生成。
- 用户手动写复盘后的智能补充与追问。

## 输入

- 今日计划：`{dailyPlans[date]}`
- 今日学习/运动/内容：`{learning[date]}`、`{exercises[date]}`、`{contents[date]}`
- 历史复盘：`{reviews[]}`
- 长期目标：`{longTermGoals}`

## 输出

- 结构化复盘（见下）+ 明日建议，均须结合长期目标。

## 规划中的 Prompt（待按 PromptGuide 模板补全）

### 今天完成情况
- 简述：对照今日计划，客观评估完成度，不粉饰也不苛责。

### 今天最大收获
- 简述：提炼今日最有价值的 1 个认知/产出，便于沉淀。

### 今天最大问题
- 简述：指出今日最该改进的 1 件事，并给原因。

### 明日建议
- 简述：生成明日 1–3 条高优先级行动，呼应长期目标。
