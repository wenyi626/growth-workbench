# Home.md — 首页 / 今日 AI Prompt

> 集中维护「今日首页」相关的 AI 能力。当前对应本地规则 `AI.generateTodayPlan`。

## 目的

根据用户目标与历史，生成可执行的「今日计划」与优先级，帮用户把一天聚焦在最重要的事上。

## 适用场景

- 打开 App 首页时的一键「生成今日计划」。
- 用户手动触发「帮我安排今天」。

## 输入

- 长期目标：`{longTermGoals}`
- 今日待办 / 每日计划：`{dailyPlans[date]}`
- 最近学习 / 复盘：`{learning[-3]}`、`{reviews[-1]}`
- 当前日期与空闲时间：`{date}`、`{profile.availableTime}`

## 输出

- 今日计划列表（带优先级与预计耗时）。
- 一句话「今天最该推进的一件事」。

## 规划中的 Prompt（待按 PromptGuide 模板补全）

### 今日计划生成
- 对应现状：`AI.generateTodayPlan`
- 简述：基于目标与近期进度，排出今日 3–5 项高优先级任务。

### 每日优先级提醒（未来）
- 简述：结合身体/财富/自媒体状态，动态调整今日重心。
