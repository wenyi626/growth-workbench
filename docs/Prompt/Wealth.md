# Wealth.md — 财富模块 AI Prompt

> 集中维护「财富」相关的 AI 能力。当前对应本地规则 `AI.wealthReview`。

## 作用

把资产/交易数据转化为可执行的财富决策建议，帮用户建立长期投资纪律。

## 适用场景

- 财富页的复盘、仓位/风险/配置分析。
- 新增交易前的「该不该买/卖」自检。

## 输入

- 资产：`{assets[]}`（quantity/currentPrice/targetAllocation/currency）
- 交易：`{transactions[]}`（type/quantity/price/reason/decisionType/risk）
- 财富快照：`{wealthSnapshots[]}`
- 长期目标中财富相关项：`{longTermGoals}`

## 输出

- 按子能力分别返回分析与建议（见下），均须附依据。

## 规划中的 Prompt（待按 PromptGuide 模板补全）

### 仓位分析
- 简述：对比实际持仓与目标配置，指出偏离项与再平衡空间。

### 风险分析
- 简述：评估单一标的/行业集中度、回撤与流动性风险。

### 交易记录
- 简述：对新交易做「决策质量」复盘，对照原定 reason/risk 看执行偏差。

### 资产配置
- 简述：结合目标与风险偏好，给出长期配置比例建议。

### 投资纪律
- 简述：基于用户历史交易，提示常见纪律违背（追高、频繁交易等）。

### 未来自动分析能力
- 简述（规划）：定期自动巡检组合，主动推送偏离预警与再平衡建议。
